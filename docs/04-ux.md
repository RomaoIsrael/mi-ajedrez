# 04 · Experiencia de usuario

Regla de oro: **UNA PANTALLA = UNA DECISIÓN PRINCIPAL.** Un solo botón primario visible; lo demás es secundario o está plegado.

## 1. Flujos de usuario

### 1.1 Primer uso (principiante absoluto)

```
Splash (1 s) → "¿Has jugado antes?" → [Nunca]
  → Micro‑lección 1: "Este es el tablero" (toca una casilla)          ← aprende haciendo en < 30 s
  → Crear cuenta opcional ("Guarda tu progreso" / Continuar como invitado)
  → Objetivo ("Aprender desde cero", "Jugar con amigos", …) + tiempo diario (5–60 min)
  → Elegir coach (Mentor por defecto) y modo (Niño / Adulto)
  → Home con "CONTINUAR ENTRENAMIENTO" → Nivel 0, nodo "El tablero"
```

### 1.2 Primer uso (conoce las reglas o más)

```
"¿Has jugado antes?" → [Conozco las reglas … Competitivo]
  → Test inicial adaptativo (10–20 ejercicios, ~8 min, se puede saltar)
  → Resultado: nivel + radar inicial + "Empezarás en: Táctica básica" (explicado)
  → Objetivo + tiempo diario → Home
```

### 1.3 Bucle diario

```
Home → CONTINUAR ENTRENAMIENTO
  → Plan del día (p.ej. 20 min): repaso SRS → concepto → partida temática → revisión
  → Resumen de sesión: qué mejoraste, XP ganada por aprendizaje, próximo paso
  → (Coach decide la siguiente recomendación)
```

### 1.4 Partida → aprendizaje

```
Elegir rival (nivel + personalidad) + reloj + Coach Mode on/off
  → Partida (pistas progresivas si Coach Mode)
  → Fin → Post‑partida: resultado, precisión humana, LOS 3 MOMENTOS
  → Momento 3 "Esto debes aprender" → mini‑lección → "Inténtalo otra vez" (misma posición)
  → Posiciones de error guardadas → puzzles personales programados (SRS)
```

### 1.5 Memoria pedagógica ante un error repetido

```
1.ª vez: explicación completa + flechas + mini‑ejercicio
2.ª vez: recordatorio corto ("Otra vez una pieza sin defensa, ¿recuerdas la pregunta 6?")
3.ª vez: pregunta ("¿Qué pieza tuya está indefensa ahora?") antes de explicar
4.ª vez: evaluación sin ayuda; si falla → se reprograma el concepto (◐)
```

## 3. Onboarding y test inicial

**Pregunta:** ¿Has jugado antes? → Nunca · Conozco las reglas · Juego ocasionalmente · Juego frecuentemente · Juego en club · Competitivo.

**Test adaptativo** (salto por dificultad; se detiene al estabilizar la estimación):

| Bloque | Ejemplos (originales) | Mide |
|---|---|---|
| Reglas (3) | ¿Puede enrocar aquí? · ¿Es jaque mate o ahogado? · Captura al paso | Reglas |
| Visión (3) | Toca todas las piezas indefensas · ¿Qué captura el caballo? | Visión |
| Táctica (4) | Mate en 1 · horquilla · clavada · mate en 2 | Táctica |
| Estrategia (3) | ¿Cuál es la peor pieza blanca? · Elige el mejor plan (3 opciones) | Estrategia |
| Finales (3) | Regla del cuadrado · oposición · ¿Tablas o gana? | Finales |
| Cálculo (2) | Escribe la línea de 3 plies sin mover | Cálculo |

Salida: nivel inicial (§05), ratings iniciales con alta incertidumbre (Glicko RD alto), estados de concepto sembrados (○ o ●, nunca ★ sin evidencia repetida).

## 5. Modo Niños vs Modo Adulto

| Aspecto | Niños | Adulto |
|---|---|---|
| Textos | ≤ 15 palabras, historias ("El caballo saltarín") | Precisos, técnicos progresivos |
| Coach | Personaje animado (caballo Kavi) | Avatar sobrio con tono elegido |
| Recompensas | Pegatinas, mundo que crece, misiones | XP, insignias discretas |
| Animaciones | Más presentes (sin exceso) | Mínimas |
| Piezas | Set Kids por defecto | Royal Modern |
| Social/chat | Desactivado | Opcional (Fase 3) |
| Reglas | **Idénticas y reales** | Idénticas |

## 6. Tablero interactivo

Arrastrar · tocar pieza + destino · solo movimientos legales (puntos) · flechas y resaltados con clic derecho/pulsación larga · retroceder/avanzar · girar · coordenadas on/off · animaciones · premove (solo avanzado) · confirmación de jugada opcional para principiantes · entrada accesible por teclado/voz.

## 7. Modos de partida y relojes

Modos: Libre · Educativa · Temática (objetivo concreto, p.ej. "enroca antes de la jugada 10") · Desde apertura · Desde medio juego · Desde final · Contra IA · Coach Mode · Sin pistas · Entrenamiento.

Relojes: sin reloj · 1+0 · 3+0 · 3+2 · 5+0 · 5+3 · 10+0 · 15+10 · 30 min · personalizado. A principiantes se les **recomienda** sin reloj o 15+10 y se ocultan los ritmos bala en su selector (accesibles en "Más").
